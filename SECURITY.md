# Security

Please report vulnerabilities privately through https://kotecharts.com/contact (subject
"Security") or GitHub's private vulnerability reporting on this repository — not in a public issue.
We acknowledge reports within a few days. The hosted API also publishes
https://kotecharts.com/.well-known/security.txt.

Never paste an API key into an issue. Keys can be revoked and regenerated at
https://kotecharts.com/account.
